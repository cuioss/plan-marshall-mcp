== Overview

Watch items for the link:../specification/store-schemas.adoc[Store Schemas Specification]: persisted identities
and paths, findings and change-ledger records, footprint reconciliation, the lesson store, and the one-time
conversion of legacy stores, whose tests should run against the real plan-marshall corpora cited here. The
sections mirror the specification. Item format and lifecycle: link:../ImplementationWatch.adoc[Implementation Watch].

== Scope Entry Record (`mcp/entry.json`)

[#PM-WATCH-STORE-1]
=== PM-WATCH-STORE-1: Stored path strings bypass any resolver redirect

Anchor:: link:../specification/store-schemas.adoc#_scope_entry_record_mcpentry_json[Store Schemas § Scope Entry Record],
link:../Requirements.adoc#PM-ARCH-4[PM-ARCH-4]
Hazard:: A store move redirected the shared path resolver, but sites that matched a path-shaped string captured
elsewhere (an epic spec path captured as `source_id` in a plan's request) never passed through it.
Guard:: Cross-scope references are persisted as ids, never paths. The one persisted absolute path,
`workspace_root`, is re-canonicalised and confinement-checked on every read; a test relocates the checkout and
asserts refusal or re-resolution, never use of the stale path.
Source:: orchestrator-refactor PLAN-03 D3.

[#PM-WATCH-STORE-19]

Anchor:: link:../specification/store-schemas.adoc#lesson-record[Store Schemas § Lesson Record]
