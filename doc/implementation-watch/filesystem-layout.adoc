== Overview

Watch items for the link:../specification/filesystem-layout.adoc[Filesystem Layout Specification]: store
relocation, plan enumeration across worktrees, missing versus empty locations, and the agreement between the
documented layout and the resolver. The sections mirror the specification. Item format and lifecycle:
link:../ImplementationWatch.adoc[Implementation Watch].

== Repository Workspace Layout (`.plan/`)

[#PM-WATCH-FS-1]
=== PM-WATCH-FS-1: The layout documentation and the resolver agree

Anchor:: link:../specification/filesystem-layout.adoc#_repository_workspace_layout_plan[Filesystem Layout § Repository Workspace Layout],
link:../specification/filesystem-layout.adoc#archives[Filesystem Layout § Plan & Epic Archives],
link:../Requirements.adoc#PM-IMPL-5[PM-IMPL-5]
Hazard:: The documentation stated one archive path while the resolver produced another.
Guard:: Location resolution lives in one resolver; a build-time test renders its path templates and compares them with
the layout tree in this specification (generated block or checked table), extending the documentation drift gate
beyond DSL diagrams.
Fixture:: legacy documentation `.plan/archived-plans/{date}-{plan_id}` vs resolver
`.plan/local/archived-plans/{date}-{plan_id}`.
Source:: process-compliance PLAN-13 D2.

[#PM-WATCH-FS-2]
=== PM-WATCH-FS-2: Missing is not empty

Anchor:: link:../specification/filesystem-layout.adoc#_repository_workspace_layout_plan[Filesystem Layout § Repository Workspace Layout]
Hazard:: A nonexistent archived path returned success, byte-identical to an empty plan directory.
Guard:: Resolvers return `absent` for a missing path, distinct from an existing empty one (the inbox `no_file` vs
`empty_file` distinction is the model); test both.
Source:: post-run-quality PLAN-PRQ-10 D0.

[#PM-WATCH-FS-3]
=== PM-WATCH-FS-3: Live-plan enumeration covers worktrees

Anchor:: link:../specification/filesystem-layout.adoc#_worktree_path_resolution_same_filesystem_invariant[Filesystem Layout § Worktree Path Resolution],
link:../Requirements.adoc#PM-ARCH-5[PM-ARCH-5]
Hazard:: A dedup gate read no worktree-resident plan and reported clean.
Guard:: One enumerator covers `.plan/local/plans/*` and `.plan/local/worktrees/*/.plan/local/plans/*` and returns
`could_not_look` for unreadable locations, distinct from clean; test with a worktree-resident plan.
Fixture:: lesson `2026-09-03-23-006`.
Source:: post-run-quality PLAN-PRQ-05 F2.

[#PM-WATCH-FS-4]
=== PM-WATCH-FS-4: A store relocation never leaves two live writer locations

Anchor:: link:../specification/filesystem-layout.adoc#shared-epic-worktree[Filesystem Layout § Shared Epic Worktree],
link:../Requirements.adoc#PM-ARCH-7[PM-ARCH-7]
Hazard:: The orchestrator store moved without a redirect, and some writers kept the old location.
Guard:: The switch of the epic ledger into the shared worktree goes through the cutover guard; a test writes through
every consumer after the switch and asserts that no write lands in the primary checkout's `.plan/orchestrator/`.
Source:: orchestrator-refactor epic queue annotations (PLAN-01).
