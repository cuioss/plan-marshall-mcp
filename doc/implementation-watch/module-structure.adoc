== Dependency Rules

[#PM-WATCH-MOD-1]
=== PM-WATCH-MOD-1: Clients never reach the engine

Anchor:: link:../specification/module-structure.adoc#dependency-rules[Module Structure § Dependency Rules],
link:../Requirements.adoc#PM-IMPL-1[PM-IMPL-1]
Hazard:: One convenience dependency from a client module to `pm-mcp-core`, `pm-mcp-workflow` or a provider module
lets the CLI or the web server run engine or store code in its own process, bypassing the runtime as the only writer;
`jackson-databind` in `pm-mcp-api` pulls reflection-heavy binding into the plain native CLI.
Guard:: A build-time dependency guard (Maven enforcer or an architecture test over the resolved dependency trees)
fails when any module under `pm-mcp-clients` depends, directly or transitively, on `pm-mcp-core`, `pm-mcp-workflow`
or a module under `pm-mcp-providers`, when a provider module depends on `pm-mcp-workflow`, and when `pm-mcp-api`
depends on anything but `jackson-core`; control: a deliberately added dependency in a test fixture module trips the
guard.
Source:: PM-MCP client architecture design review, operator decisions of 2026-09-28 (Z1-3); no plan-marshall defect record.

== Binaries & Build Types

[#PM-WATCH-MOD-2]
=== PM-WATCH-MOD-2: The release is exactly four binaries with a complete SBOM

Anchor:: link:../specification/module-structure.adoc#binaries[Module Structure § Binaries & Build Types],
link:../specification/cli-and-security/01-cli-and-installer.adoc#installation-layout[CLI & Security § Installation Layout],
link:../Requirements.adoc#PM-DIST-1[PM-DIST-1]
Hazard:: A release profile that packs a stray artifact, misses a binary or its digest, or builds the SBOM from the
Maven graph only leaves the npm packages of the web application unaccounted for.
Guard:: The release build's output is checked: `bin/` holds exactly `pm-mcp`, `pm-mcpd`, `pm-mcp-exec`, and
`pm-mcp-web`, each with its SHA-256 digest, and nothing else; the CycloneDX SBOM lists every package of
`pm-mcp-web-app/package-lock.json` with its pinned version next to the Java dependencies.
Source:: PM-MCP client architecture design review, operator decisions of 2026-09-28 (Z1-17, Z1-19.1); no plan-marshall defect record.
