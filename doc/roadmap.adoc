== Overview

This document defines the staged delivery sequence and actionable implementation tasks for *plan-marshall-mcp* (`PM-MCP`), bridging the normative requirements in link:Requirements.adoc[Requirements] and the technical blueprints in link:Specification.adoc[Specification].

Project prefix: `PM-` | Status: Pre-implementation (`PLANNED`)


1. *Foundation (Milestones 1–4)*: Spike verifications, always-on runtime with `pm-mcp serve` STDIO relay, core DSL & state stores, and the job runtime with operator enrolment.
2. *Native Core Stores & Services (Milestones 5–6)*: Differential-tested PM-MCP-native stores, build server with native parsers, CI jobs, token-lane credentials, domain descriptors, configuration migration, and the operator release verb.
3. *Hypermedia Workflow Phases (Milestones 7–11)*: Phase-by-phase build-out (`init` -> `refine`/`outline` -> `plan`/`execute` -> `finalize` -> `epics`), closed by the lifecycle gate that offers the plan lifecycle in enrolled projects.
4. *Platform Services & Client Distribution (Milestones 12–13)*: Warm LSP pool, upstream MCP proxy, dynamic skill serving, and client bundle distribution.
