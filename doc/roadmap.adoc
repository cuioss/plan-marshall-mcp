== Overview

This document defines the staged delivery sequence and actionable implementation tasks for *plan-marshall-mcp* (`PM-MCP`), bridging the normative requirements in link:Requirements.adoc[Requirements] and the technical blueprints in link:Specification.adoc[Specification].

Project prefix: `PM-` | Status: Pre-implementation (`PLANNED`)

Each milestone ships independently and is verified against `plan-marshall` baselines before the next milestone begins. The sequence follows the transition strategy (`link:Requirements.adoc#PM-MIG-1[PM-MIG-1]`):
1. *Foundation (Milestones 1–4)*: Spike verifications, native daemon binary, core DSL & state stores, and the job runtime / executor adapter.
2. *Ported Core Stores & Services (Milestones 5–6)*: Differential-tested store ports, build server with native parsers, CI jobs, and token-lane credentials.
3. *Hypermedia Workflow Phases (Milestones 7–11)*: Phase-by-phase replacement (`init` -> `refine`/`outline` -> `plan`/`execute` -> `finalize` -> `epics`).
4. *Platform Services & Distribution Switch (Milestones 12–13)*: Warm LSP pool, upstream MCP proxy, dynamic skill serving, and client bundle distribution.
