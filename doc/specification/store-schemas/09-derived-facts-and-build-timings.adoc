[#derived-facts]
== Derived Facts Store (`<PM_MCP_BASE>/projects/<project_id>/derived-facts.json`)

A value the server can observe is derived, never configured; an override exists only where a derivation input can be ambiguous (`project.json` `ci_provider` and `merge_method`, `domains.json`, `local-config.json` `envelope_budget_tokens`). The derived values are cached in one per-project store of owner class *cache*: deleting it only forces re-derivation. The store is written under its own lock `locks/derived-facts.lock`, which comes late in the total lock order (after the local configuration lock, xref:13-leases-integrity-testing.adoc#lock-free-snapshot-reads[Lock-Free Snapshot Reads, Transaction Locks & Leases (`PM-IMPL-7`)]), so a refresh triggered by a read inside a plan, epic, or workspace transaction (a guard evaluation included) takes it after the scope lock the transaction already holds.

* *Local derivations* (inputs read from the repository or the machine) are recomputed whenever their `input_digest` (SHA-256 over the canonical derivation inputs) changes.
* *Network derivations* (inputs read from a provider) hold for the validity period of link:../timeouts/03-retention-host-config.adoc#network-derivation-validity[Timeouts & Budgets Specification, Network Derivation Validity] and are additionally refreshed by the project-setup reconcile and by `pm-mcp enter`.
* *Failure*: A failed derivation keeps the last value with `state: stale` (or `failed` when no value was ever derived) and records `failure`; every gate or guard that depends on a `stale` or `failed` fact evaluates `indeterminate` (`COULD_NOT_EVALUATE`, the `guard_indeterminate` condition), never pass.
* *Fact kinds* are a closed enumeration open for registration: a new kind is added to `kind` below and to the kind table together with its value schema, its class, and its inputs.
* *Class per entry*: The entry's `source.class` records how its value was obtained. `ci_provider` is `local` when the remote host alone decides it and `network` when a provider probe did; `base_branch_default` is `network` once the provider's default branch confirmed the local `origin/HEAD`. A network entry follows the network validity rule.
* *Provider derivations*: Network kinds are derived through the project's provider integration (`pm-mcp-ci`, the variant selected for the provider) with the agent credential; a derivation the credential is not permitted to perform fails (`state: failed`, `failure.reason` naming the missing permission), and the dependent gates evaluate `indeterminate`.
* *Operator-Only Facts*: `agent_identity` is operator-only: it is shown by `pm-mcp status` and the operator CLI and used server-side (committer identity, setup checks), and it never appears in a model-facing representation, resource (including `pm://project/config`), or tool result (link:../hypermedia-format/01-representation-and-link-forms.adoc#model-facing-minimality[Hypermedia Format Specification, Model-Facing Minimality]).

[source,json]
----
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "$id": "https://cuioss.de/plan-marshall-mcp/schemas/derived-facts.json",
  "title": "DerivedFactsStore",
  "type": "object",
  "required": ["format_version", "facts"],
  "additionalProperties": false,
  "properties": {
    "format_version": { "type": "integer", "const": 1 },
    "facts": {
      "type": "object",
      "description": "One entry per fact, keyed by <kind> or <kind>:<qualifier> (for example domain_activation:java).",
      "propertyNames": { "pattern": "^[a-z][a-z0-9_]{0,47}(:[A-Za-z0-9_.-]{1,128})?$" },
      "additionalProperties": { "$ref": "#/$defs/entry" }
    }
  },
  "$defs": {
    "entry": {
      "type": "object",
      "required": ["kind", "value", "source", "input_digest", "derived_at", "state"],
      "additionalProperties": false,
      "properties": {
        "kind": {
          "type": "string",
          "enum": ["base_branch_default", "push_remote", "ci_provider", "merge_methods_allowed", "merge_queue_enforced", "branch_up_to_date_required", "required_checks", "signed_commits_required", "checks_visible", "agent_identity", "git_native_capability", "domain_activation", "active_profiles", "module_discovery", "cost_calibration"]
        },
        "value": { "description": "Kind-specific value, validated against the value schema registered for the kind; null only with state failed." },
        "source": {
          "type": "object",
          "required": ["derivation", "class"],
          "additionalProperties": false,
          "properties": {
            "derivation": { "type": "string", "pattern": "^[a-z][a-z0-9_.-]{0,63}$", "description": "Identifier of the derivation that produced the value." },
            "class": { "type": "string", "enum": ["local", "network"] }
          }
        },
        "input_digest": { "type": "string", "pattern": "^[0-9a-f]{64}$" },
        "derived_at": { "type": "string", "format": "date-time" },
        "state": { "type": "string", "enum": ["current", "stale", "failed"] },
        "failure": {
          "type": ["object", "null"],
          "additionalProperties": false,
          "required": ["reason", "at"],
          "properties": {
            "reason": { "type": "string", "maxLength": 500 },
            "at": { "type": "string", "format": "date-time" }
          }
        }
      }
    }
  }
}

[#derived-fact-kinds-discovery-calibration]
=== Derived fact kinds: `module_discovery`, `cost_calibration`

The value schemas of the two fact kinds that replace the former separate discovery cache and cost calibration stores. Both are local derivations, keyed by kind alone (no qualifier), and follow the entry rules above: deleting the store only forces a re-crawl and a recalibration.

*`module_discovery`*: the structural snapshot of link:../domain-extensions/03-module-discovery.adoc#_server_owned_module_discovery_enrolled_discovery_jobs[Domain Extensions Specification, Server-Owned Module Discovery]. `input_digest` is the descriptor tree hash over the live descriptor content of the worktree the discovery ran in; the snapshot is a cache, never the gatekeeper (a module directory present on disk but absent from it is still discovered). Facts that only a lazy enrolled discovery job provides are added under the module when that job ran and are dropped with the snapshot when the digest changes.

[source,json]
----
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "$id": "https://cuioss.de/plan-marshall-mcp/schemas/fact-module-discovery.json",
  "title": "ModuleDiscoveryFactValue",
  "type": "object",
  "required": ["descriptor_tree_hash", "modules", "diagnostics"],
  "additionalProperties": false,
  "properties": {
    "descriptor_tree_hash": { "type": "string", "pattern": "^[0-9a-f]{64}$", "description": "Equals the entry's input_digest." },
    "modules": {
      "type": "array",
      "items": {
        "type": "object",
        "required": ["module_id", "build_system", "path", "facts"],
        "additionalProperties": false,
        "properties": {
          "module_id": { "type": "string", "pattern": "^[A-Za-z0-9][A-Za-z0-9_.-]{0,56}$", "description": "identifiers.adoc, module_id" },
          "build_system": { "type": "string", "enum": ["maven", "gradle", "npm", "pyproject", "documentation", "marshall-plugin"] },
          "path": { "type": "string", "description": "Repository-relative module directory; '.' for the root." },
          "parent": { "type": ["string", "null"], "description": "module_id of the reactor parent, if any." },
          "facts": { "type": "object", "description": "Extracted module facts of the build system's descriptor parser (Domain Extensions, Server-Owned Module Discovery)." },
          "job_facts": {
            "type": "object",
            "description": "Facts from lazy enrolled discovery jobs, keyed by discovery template name (enrolment build.discovery_templates).",
            "additionalProperties": {
              "type": "object",
              "required": ["job_id", "value"],
              "additionalProperties": false,
              "properties": {
                "job_id": { "type": "string", "pattern": "^[bcgrp]-[0-9a-f]{16}$" },
                "value": { "type": "object" }
              }
            }
          }
        }
      }
    },
    "diagnostics": {
      "type": "array",
      "description": "Per-descriptor parse failures; a failure never aborts discovery of the other modules.",
      "items": {
        "type": "object",
        "required": ["path", "message"],
        "additionalProperties": false,
        "properties": {
          "path": { "type": "string" },
          "message": { "type": "string", "maxLength": 2000 }
        }
      }
    }
  }
}
----

*`cost_calibration`*: the calibrated size-to-token table of link:../dispatch-and-effort/01-task-envelopes.adoc#cost-sizing[Model Jobs & Effort Specification, Cost Sizing], recomputed by `record-metrics` from the measured `metrics.json` population of the project's completed plans; `input_digest` covers the ids and digests of the metrics stores in that population. Absent or `failed`, the compiled table applies with `basis: uncalibrated`; every figure derived from the table carries the basis of the table it used.

----
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "$id": "https://cuioss.de/plan-marshall-mcp/schemas/fact-cost-calibration.json",
  "title": "CostCalibrationFactValue",
  "type": "object",
  "required": ["table", "population_count", "calibrated_at"],
  "additionalProperties": false,
  "properties": {
    "table": {
      "type": "object",
      "required": ["XS", "S", "M", "L", "XL", "XXL"],
      "additionalProperties": false,
      "properties": {
        "XS": { "type": "integer", "minimum": 1 },
        "S": { "type": "integer", "minimum": 1 },
        "M": { "type": "integer", "minimum": 1 },
        "L": { "type": "integer", "minimum": 1 },
        "XL": { "type": "integer", "minimum": 1 },
        "XXL": { "type": "integer", "minimum": 1 }
      }
    },
    "population_count": { "type": "integer", "minimum": 1, "description": "Envelopes with measured token components the table was calibrated from." },
    "calibrated_at": { "type": "string", "format": "date-time" }
  }
}

[#build-timings-store]
== Build Timings Store (`<PM_MCP_BASE>/projects/<project_id>/build-timings.json`)

The learned budgets of one project (link:../job-runtime/03-parsers-and-gates.adoc#_adaptive_timeout_learning[Job Runtime Specification, Adaptive Timeout Learning]; allocation in link:../timeouts/01-job-budgets-and-waits.adoc#job-budgets[Timeouts & Budgets Specification, Job Budgets]), keyed by the canonical budget key. It lives in the per-project machine store, so a moved checkout keeps its budgets; there is no machine-level timings store. Written only by the runtime at job fate, under `projects/<project_id>/locks/build-timings.lock` (xref:13-leases-integrity-testing.adoc#lock-free-snapshot-reads[Lock-Free Snapshot Reads, Transaction Locks & Leases (`PM-IMPL-7`)]). A key that module discovery no longer yields is pruned when the discovery snapshot changes.

[source,json]
----
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "$id": "https://cuioss.de/plan-marshall-mcp/schemas/build-timings.json",
  "title": "BuildTimingsStore",
  "type": "object",
  "required": ["format_version", "keys"],
  "additionalProperties": false,
  "properties": {
    "format_version": { "type": "integer", "const": 1 },
    "keys": {
      "type": "object",
      "description": "Budget keys (timeouts.adoc, Job Budgets): <build_system>:<verb>[@<module_id>] (a verb's template names its build profile literally, so the key carries none), git:<operation>, ci:<operation> (the contract operation name; one key for the native in-process operation and the CLI job alike), llm:<role_key> (model jobs, one key per role whatever the harness). project_script keys never learn.",
      "propertyNames": { "pattern": "^[a-z][a-z0-9_]{0,31}:[a-z][a-z0-9.-]{0,63}(@[A-Za-z0-9][A-Za-z0-9_.-]{0,56})?$", "maxLength": 155 },
      "additionalProperties": { "$ref": "#/$defs/keyTimings" }
    }
  },
  "$defs": {
    "baseline": {
      "type": "object",
      "required": ["learned_seconds", "observations"],
      "additionalProperties": false,
      "properties": {
        "learned_seconds": { "type": ["integer", "null"], "minimum": 1, "description": "Blended baseline L; null before the first observation." },
        "observations": { "type": "integer", "minimum": 0 }
      }
    },
    "keyTimings": {
      "type": "object",
      "required": ["clean", "poisoned", "cold", "escalation_seconds", "last_observed_at"],
      "additionalProperties": false,
      "properties": {
        "clean": { "$ref": "#/$defs/baseline", "description": "Finished runs without residue or cold start: the baseline L used for allocation." },
        "poisoned": { "$ref": "#/$defs/baseline", "description": "Residue-poisoned runs; used only while clean.observations == 0." },
        "cold": { "$ref": "#/$defs/baseline", "description": "Cold rebuilds; used only while clean.observations == 0." },
        "escalation_seconds": { "type": ["integer", "null"], "minimum": 1, "description": "One-shot escalation budget E set by a timed_out run; cleared by the next finished run." },
        "last_observed_at": { "type": ["string", "null"], "format": "date-time" }
      }
    }
  }
}
