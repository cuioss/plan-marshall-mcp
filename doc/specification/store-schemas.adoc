== Overview

This document defines the normative JSON and JSONL storage schemas for *plan-marshall-mcp* (`PM-MCP`). Every persisted file includes an explicit `format_version` integer; before 1.0 a binary accepts exactly the current version of each file kind and refuses any other with a named reason, and nothing is migrated on startup (`PM-IMPL-2`, xref:store-schemas/01-format-and-session-log.adoc#format-versioning[Format Versioning & Atomic Write Discipline]). `PM-MCP` shares no store with legacy `plan-marshall`: its stores live under `.marshall/` and `<PM_MCP_BASE>` (`PM-MIG-2`), and it imports nothing from legacy `plan-marshall`. Legacy formats are not part of this specification: the legacy -> target mapping of the differential tests lives in test code only (`PM-TEST-2`).
