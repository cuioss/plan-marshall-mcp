== Overview

This document defines the normative hypermedia state representation format (HATEOAS) and deterministic Token-Oriented Object Notation (TOON) encoding rules for *plan-marshall-mcp* (`PM-MCP`). Every call to `pm_state` or `pm_do` returns an authoritative state representation rendered in TOON containing the scope identifier, closed state and phase names, optional vocabulary skill URI, contextual facts, and the set of valid hypermedia links.
