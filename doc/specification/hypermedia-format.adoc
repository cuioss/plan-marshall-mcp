== Overview

This document defines the normative hypermedia state representation format (HATEOAS) and deterministic Token-Oriented Object Notation (TOON) encoding rules for *plan-marshall-mcp* (`PM-MCP`). Every call to `pm_state` or `pm_do` returns an authoritative state representation rendered in TOON containing the scope identifier, closed state and phase names, optional vocabulary skill URI, contextual facts, and the set of valid hypermedia links. Links are offered only where a model acts: on the task entities a worker holds, on the states the entry session drives (the bootstraps and the project setup), and as the answer links of open question records; the representation of a plan or an epic is otherwise a view.
