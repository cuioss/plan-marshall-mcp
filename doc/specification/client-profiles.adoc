== Overview

This document specifies the data-driven client profile schema, on-the-fly placeholder rendering rules, three-tier environment identity detection and mismatch auditing, neutral fallback profile behavior, and embedded client bundle `bundle-manifest.json` schema for *plan-marshall-mcp* (`PM-MCP`). By translating vocabulary skills, model-job prompts, and host tool idioms at request time from the scope's persisted session history (`sessions.jsonl`, current identity = last row), `PM-MCP` serves Claude Code (`claude`), OpenCode (`opencode`), Antigravity (`antigravity`), Codex (`codex`), and unknown MCP hosts (`neutral`) concurrently without static per-runtime corpus generation; each profile also declares its harness's headless launch contract for the model jobs the server launches.
