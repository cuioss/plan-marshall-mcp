== Overview

This document specifies the data-driven client profile schema, on-the-fly placeholder rendering rules, the entry identity audit with host detection, neutral fallback profile behavior, and the embedded client bundle `bundle-manifest.json` schema for *plan-marshall-mcp* (`PM-MCP`). By translating vocabulary skills, worker launch prompts, and host tool idioms at request time for the client the calling connection's relay declares (`pm-mcp serve --client <client>`), or for the harness a worker's role names, `PM-MCP` serves Claude Code (`claude`), OpenCode (`opencode`), Antigravity (`antigravity`), Codex (`codex`), and unknown MCP hosts (`neutral`) concurrently without static per-runtime corpus generation. Each profile also declares its harness's headless launch contract and its `worker` block: whether the harness may host workers, whether its interactive session may take tasks, and the measured per-host values of the task protocol and of supervision.
