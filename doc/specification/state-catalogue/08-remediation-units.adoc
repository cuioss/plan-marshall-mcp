== Remediation Units
_See Requirement link:../../Requirements.adoc#PM-WF-16[PM-WF-16: Reusable Compound Sub-Workflows & Config-Driven Git Commit/Push]_

The self-remedy of a failure class is a sub-workflow unit per class (`scope subworkflow`), called by the phase units (link:../phase-workflows/01-planning-phases-1-2.adoc#_remediation_policy_calls[Phase Workflows Specification, Remediation Policy Calls]). The units are project-owned templates within compiled invariants; this catalogue documents the default units. Every state declares `phase inherit`.

*Contract*: Parameters `retry_budget`, `fix_budget`, `waiver_wait_seconds`, and `actions` (the subset of `retry`, `fix`, `loop_back` the call admits; the plan instance's composition rules may narrow it, for example `actions=[retry]` for a `land` plan), bounded by the compiled hard caps (retry `5`, fix `5`, waiver wait `86400` s); the plan instance carries the effective ceilings with their source. Budgets are counted per plan and class, persisted, and never reset (link:../store-schemas/14-plan-instance-waivers-questions.adoc#policy-counter[Store Schemas Specification, Remediation Budget Accounting]). The exit contract is the subset of the domain outcomes `resolved`, `waived`, `exhausted`, `fix_requested` the unit can reach, plus the control outcome `stepped_out`: `waived` only where the class has a waivable gate, `fix_requested` only where the fix runs in the caller. The gather state records the evidence as failure envelopes behind untrusted resources (link:../store-schemas/14-plan-instance-waivers-questions.adoc#evidence-directory[Store Schemas Specification, Evidence Directory]); `decide` asks for one judgment, the remedy, and offers the implicit `step_out`, never guarded by a budget. A nested `git.commit_and_push` that returns `stepped_out` routes back to `decide`, and the uncommitted fix is not charged. No primitive writes a waiver: the waived path exists only as the `waived` terminal, produced by the gather state (`waiver.lookup`) or the waiver wait.

*`decide` validation* (common to every unit): `retry` (`submit`, `reason: enum[flaky|infra|timeout]`) is refused with `retry_not_applicable` when the same failure fingerprints already failed after a retry with the same reason; `fix` is charged only when its commit or revised artifact exists, and an empty commit or unchanged artifact is refused with `fix_unchanged`; `loop_back` (`submit`, `summary`) returns `fix_requested` and is charged like `fix`; `request_waiver` (`submit`, `rationale: text[1..2000]`, files a waiver request, not a decision) is offered only while `waiver_wait_seconds > 0` and the failing gate is waivable. Each link is offered only when the call's `actions` admit it and its budget is left.

|inherit

|The unit's gather state (`failures`, `over`, `cancelled`), triage state (`triaged_with_fix`), or waiver wait (`raised`).

|link:../store-schemas/14-plan-instance-waivers-questions.adoc#gap-record[Store Schemas Specification, Gap Record]

[#state-catalogue-remediation-spend]
=== `remediation.spend`

A degenerate unit: no `retry`, no `fix`, and no resting link state (so it never returns `stepped_out`); spend is raise-only.
