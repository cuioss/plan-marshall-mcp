[#state-catalogue-adjudicate]
== Unit `question.adjudicate`
_See Requirement link:../../Requirements.adoc#PM-WF-18[PM-WF-18: Question Recommendation Score & Decision Panel]_

The adjudication, its blind input, the decision rule, and the record are specified in link:../model-work/10-decision-panel.adoc#adjudication[Model Work Specification, Decision Panel]; the unit and its binding in link:../workflow-dsl/02-units-jobs-decisions.adoc#question-adjudicate-unit[Workflow DSL Specification, Adjudication Unit]. The unit (`question-adjudicate.pmwf`, compiled only) is run by every question state of every scope (`awaiting_user`, among them `init.recipe-candidate`, `init.sibling-collision`, `init.domain-choice`, `refine.awaiting_answers`, `outline.awaiting_answers`, `outline.review`, `execute.task-question`, every `<state>.asked`, and the question states of the project setup) for the scope's new question set before it is delivered. Its states declare `phase inherit` and are named `adjudicate.<state>`; no state of the unit is a link state, and none asks the user or the operator. Exit contract: `auto_decided` and `delivered`; the engine routes `stepped_out` like `delivered`.

|[[state-adjudicate.check]]`adjudicate.check`
|inherit
|`auto`
|Entering a question state (start state, the new question set bound).
|`question.check-adjudication`: the class's effective mode is `panel`, the panel passes `panel_invalid` and `panel_not_diverse`, every question's `decision_kind` is in `auto_kinds`, and the set's score is at least `min_score`.

|[[state-adjudicate.panel]]`adjudicate.panel`
|inherit
|`job`
|`adjudicate.check` (`eligible`).
|`job llm panel role each question.panel-roles`: one fresh task per configured panel role, each on its own entity `panel-<question_set>-<role>` with the blind facts and one closing link `submit:panel`; never offered to the entry session. The return evaluation records each answer; a task without a valid answer, and every task still open when the panel wait expires (cancelled), counts as missing. An empty role list completes the state in the entering transaction.
|`collected` -> `adjudicate.decide`; `lost` (no task of the list could be served) -> `adjudicate.delivered`.
|link:../model-work/10-decision-panel.adoc#panel-blind-input[Model Work Specification, Blind Input]; link:../timeouts/01-job-budgets-and-waits.adoc#panel-wait[Timeouts & Budgets Specification, Panel Wait]

|[[state-adjudicate.decide]]`adjudicate.decide`
|inherit
|`auto`
|`adjudicate.panel` (`collected`).
|`question.decide-agreement`: the decision rule over the asker (or the primitive of a server-raised question) and the answering panel roles, per question of the set.
|`agreed` (every question agreed) -> `adjudicate.auto-decided`; `not_agreed` (reason `disagreement`) -> `adjudicate.delivered`.
|link:../model-work/10-decision-panel.adoc#decision-rule[Model Work Specification, Decision Rule]

|[[state-adjudicate.auto-decided]]`adjudicate.auto-decided`
|inherit
|`terminal`
|`adjudicate.decide` (`agreed`).
|Terminal `auto_decided` (class `success`): its transaction writes the set's `adjudicated` lines (reason `agreement`) and answers every question with the agreed option, `channel: panel`; the question state takes the resolution outcome of that answer.
|Returns `auto_decided` to the question state.
|link:../model-work/10-decision-panel.adoc#panel-record[Model Work Specification, Record, Delivery & Audit]

|[[state-adjudicate.delivered]]`adjudicate.delivered`
|inherit
|`terminal`
|`adjudicate.check` (`ineligible`); `adjudicate.panel` (`lost`); `adjudicate.decide` (`not_agreed`).
|Terminal `delivered` (class `success`): in mode `panel` its transaction writes the set's `adjudicated` lines with the reason and the panel's answers and sets the deadline from the delivery; the set is then delivered per its mode (`auto` handling in mode `panel`).
|Returns `delivered` to the question state, which rests until the records resolve.
|link:../model-work/06-envelopes-questions-deadlines.adoc#question-delivery[Model Work Specification, Delivery, Mode & Server-Owned Deadlines]
