[#state-catalogue-execute]
== Phase 5: `execute`

Envelopes run serially: at most one envelope dispatch is `ALLOCATED` or `CLAIMED`. The plan state reacts only to `returned:<dispatch_id>`, whose return-evaluation primitive `execute.evaluate-envelope-return` declares the closed outcomes `question_pending`, `infeasible_pending`, `chain_tail`, `continue`, `all_complete`, taken in that precedence when several apply. A task that changes files inside the plan's worktree beyond its declared footprint is not reviewed: the server records `realized − declared` as unplanned changes with their provenance (task or loop-back) and lists them in the pull request body and the landing record; only a boundary breach raises `footprint_violation`.

|`phase-5-execute`
|`auto`
|`execute.verify-sweep` (`all_green`).
|Dual gate evaluated together: pending-tasks and clean-tree gate (every task terminal with its disposition, empty porcelain) and worktree freshness gate (`fresh`, `exempt`, `stale`, `undecidable` with `stale_reason`; a `baseline_red` row counts as passing for its `worktree_sha` only).

|`link`

|Model judgment. `facts`: the infeasible deliverables and their server-computed transitive dependents. `remove_deliverable:<deliverable_id>` (`submit`, `reason`), refused for the last remaining deliverable; `loop_back_outline` (`submit`, `reason`, guarded by the loop-back budget); `ask` (a question record of class `ask`; the choice stays the model's); `hand_back`.
|`remove_deliverable` -> `execute.apply-removal`; `loop_back_outline` -> `outline.deep` (deep lane) or `outline.light-regate` (light lane), phase set back to `phase-3-outline` with the worktree kept; `hand_back` -> `finalize.hand-back`.

|`auto`

[#state-catalogue-land]
== Land Lane: `land`

Plans started from `local_changes` only. The `land.*` states run in phase `phase-5-execute`. The capture of `land.worktree-init` is one-shot and never repeated. The model never authors the landed change: the plan instance's composition rules prune task allocation, `loop_back`, and in-branch fix links with reason `land_lane` and bind every policy call with `actions: [retry]`; a failure the retries cannot clear hands the plan back, and the user fixes the branch after the run.
