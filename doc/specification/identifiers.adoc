== Overview

This document is the single source of every identifier that *plan-marshall-mcp* (`PM-MCP`) defines, persists, renders, or accepts: its grammar (a regular expression and a maximum length), who generates it, the scope in which it is unique, whether it is ever reused, and where it is used. Every other specification refers to the anchor of an identifier here (for example link:identifiers/01-general-rules-and-registry.adoc#id-plan-id[`plan_id`]) instead of restating its grammar. JSON Schema `pattern` values in tool and store schemas remain in place, because a schema must be self-contained, but each one equals the grammar registered here; a schema pattern that narrows an identifier to one of its forms (for example `pm_build` accepting only build jobs) names the narrowing in this registry.

Derivation procedures stay in their owning specification (plan ID derivation and phantom-ID refusal in link:phase-workflows/01-planning-phases-1-2.adoc#_plan_id_derivation_phantom_id_refusal_guard[Phase Workflows Specification, Plan ID Derivation], the task protocol and the worker lifecycle in link:model-work.adoc[Model Work Specification], the DSL lexical grammar in link:workflow-dsl/01-grammar.adoc#_formal_ebnf_grammar_for_the_workflow_dsl[Workflow DSL Specification]); this registry holds only what an identifier looks like and how long it lives.
