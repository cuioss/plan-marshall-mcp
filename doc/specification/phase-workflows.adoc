== Overview

This document specifies the end-to-end phase state machines (Phases 1–6), transition guards, Q-Gate validation loop, change-type and scope-deviation contracts, Phase 5 envelope execution and verification sweep, Phase 6 finalize step ordering bands, `FinalizeStepDescriptor` schema, verdict currency rules, pre-merge review barrier, and cross-plan merge mutex for *plan-marshall-mcp* (`PM-MCP`).

In `PM-MCP`, the prose-driven orchestrator loops, phase handshake files (`handshakes.toon`), and intra-phase step-recording rituals (`mark-step-done`, `assert-step-recorded`) of the legacy script architecture are replaced by deterministic server-owned state machines defined in `classpath:/workflows/*.pmwf` and executed by `pm-mcp-core`.
