== Overview

This document specifies the end-to-end phase state machines (Phases 1–6), the plan outcomes with their fallback routes and remediation policy calls, the question mechanism and the operator's waivers, transition guards, the plan instance composition, the Q-Gate validation loop, the change-type and unplanned-change contracts, Phase 5 envelope execution and verification sweep, Phase 6 finalize step ordering bands and step states, `FinalizeStepDescriptor` schema, verdict currency rules, the merge path with the pre-merge review barrier and its waivable gates, and the cross-plan merge mutex for *plan-marshall-mcp* (`PM-MCP`).

In `PM-MCP`, the prose-driven orchestrator loops, phase handshake files (`handshakes.toon`), and intra-phase step-recording rituals (`mark-step-done`, `assert-step-recorded`) of the legacy script architecture are replaced by deterministic server-owned state machines defined in `classpath:/workflows/*.pmwf` and executed by `pm-workflow`.
