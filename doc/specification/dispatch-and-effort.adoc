== Overview

This document specifies the server-launched model jobs of *plan-marshall-mcp* (`PM-MCP`): task envelope bin-packing, the launch contract of a model job per harness (inline named agent or per-call flags, job-bound capability, working directory, model slots, server-composed prompt file with the contract envelope), the job lifecycle and its return evaluation, the `job_incomplete` condition, usage and spend accounting parsed from the harness output, server-owned question records, effort role resolution through the 7-level ladder to harness flags, the batch format and the screener of untrusted external text with batched triage, and epic coordination with plan emission (`emit:<plan>`) and the epic's own model jobs.

In the legacy script-and-prose architecture, sub-agent orchestration relied on prose conventions for task sizing, unverified return summaries, a host-side agent tool the orchestrator could not observe, and static build-time agent variant files that pinned models and lacked MCP tool declarations. `PM-MCP` replaces these mechanisms with server-owned envelope entities, model jobs that the server itself launches, bounds, observes, and accounts for through the harness's headless CLI, per-job composition of skills, contract, model, and effort (nothing installed per level), a two-level guard for external text (deterministic validator and zero-tool screener), and operator-mediated epic plan emission.
