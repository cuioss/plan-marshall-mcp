== Overview

This document specifies the two command-line binaries of *plan-marshall-mcp* (`PM-MCP`), cut by caller (`pm-mcp`, the harness- and model-facing client of the daemon with the relay and `enter`; `pm-operator`, the operator CLI a human runs at a terminal), the installation layout of the four release binaries, and the machine-level security mechanisms around the runtime: cross-process `FileChannel.lock()` coordination, the client bundle installer (`pm-operator client`) and its drift checks, the entry identity recorder and bootstrap entry opener (`pm-mcp enter`), token-lane credential resolution, operator channel isolation (`pm-operator`, including the `roles` verbs), the security audit log with its entry identity audit, and the optional web access the runtime serves to paired browsers (`pm-operator web`), the dependable view and question channel of the operator.

The process topology (always-on runtime, `pm-mcp serve` STDIO relay of sessions and workers), the local transport, `stdout` hygiene, runtime start/stop/drain, crash recovery, and the roles of the entry session and the workers are specified exclusively in the link:runtime-model.adoc[Runtime & Interaction Model Specification].
