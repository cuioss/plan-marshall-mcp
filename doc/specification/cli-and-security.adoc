== Overview

This document specifies the command-line binary of *plan-marshall-mcp* (`PM-MCP`) (`pm-mcp`, the interactive and host-facing client of the daemon), the installation layout of the four release binaries, and the machine-level security mechanisms around the runtime: cross-process `FileChannel.lock()` coordination, the client bundle installer (`pm-mcp client`) and its drift checks, the entry identity recorder and bootstrap entry opener (`pm-mcp enter`), the session-start hook (`pm-mcp hook session-start`), token-lane credential resolution, operator channel isolation (`pm-mcp operator`), and the security audit log.

The process topology (always-on runtime, `pm-mcp serve` STDIO relay), the local transport, `stdout` hygiene, runtime start/stop/drain, crash recovery, and logical plan sessions are specified exclusively in the link:runtime-model.adoc[Runtime & Interaction Model Specification].
