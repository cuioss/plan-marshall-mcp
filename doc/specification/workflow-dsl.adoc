== Overview

This document specifies the declarative Workflow Domain-Specific Language (DSL), Abstract Syntax Tree (AST) model, typed Java `Primitive<P, R>` execution contract, loop-back guard semantics, automated diagram generation, and the verification harnesses (including the out-of-band behavioural conformance harness for model-facing content) for *plan-marshall-mcp* (`PM-MCP`). The workflow engine and DSL reside in the plain-Java module `pm-mcp-workflow` on top of `pm-mcp-core`, with zero runtime framework dependencies, and are assembled into the native daemon by `pm-mcp-server` (link:module-structure.adoc[Module Structure Specification]).
