|[[id-runtime-token]]Runtime token
|`^[A-Za-z0-9_-]{43}$`, 43: 256 bits from `SecureRandom`, base64url without padding; no prefix, no `.`, so it is distinguished by shape from a device secret and a JWT. A secret, never an identifier of anything.

|`^pmj_[A-Za-z0-9_-]{43}$`, 47: the prefix `pmj_` plus 256 bits from `SecureRandom`, base64url without padding. A secret, not an identifier; the prefix distinguishes it by shape from the runtime token and a device secret and lets the redactor recognize it.

|One worker

|[[id-device-secret]]Device secret
|`^pmw_[A-Za-z0-9_-]{43}$`, 47: the prefix `pmw_` plus 256 bits from `SecureRandom`, base64url without padding. Opaque; a secret, not an identifier; the prefix lets the authentication seam route it by shape and lets the redactor recognize it.
|server (runtime, at pairing)
|One device
|Returned once at pairing; stored only as SHA-256; invalid after revocation or idle expiry; never reissued
|`Authorization: Bearer` from the browser on the runtime's web listener, and on no other listener link:../runtime-model/01-processes-and-transport.adoc#local-api[Runtime Model, Local API]; link:../cli-and-security/03-web-server.adoc#web-auth-seam[CLI & Security, Authentication Seam]

|[[id-pairing-code]]Pairing code
|`^[BCDFGHJKLMNPQRSTVWXZ]{8}$`, 8 (the RFC 8628 base-20 alphabet, about 34.5 bits). Displayed as `XXXX-XXXX`; input is normalized to upper case with `-` and whitespace removed before validation. Carried in a URL only in the fragment (`/pair#code=<code>`).
|server (runtime, `pm-operator web pair`)
|Machine (at most one open pairing)
|Single use; valid 5 minutes and for at most 5 failed redemptions; held in memory as SHA-256; lost on runtime restart
