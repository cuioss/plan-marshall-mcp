== Overview

This document defines the normative Model Context Protocol (MCP) tool schemas, resource URI templates, skill delivery surface, and error/result envelope contracts for *plan-marshall-mcp* (`PM-MCP`). It specifies the JSON Schema (Draft 2020-12) definitions for the core workflow verbs (`pm_state`, `pm_do`) with the addressing of bootstrap entries and job-bound connections, discovery tools (`pm_plans`, `pm_epics`), orthogonal service tools (`pm_build`, `pm_lsp`), and tool-based skill retrieval (`pm_skill`, `pm_skills`, `pm_skill_file`), alongside the strict separation between JSON-RPC protocol errors, tool execution errors (`isError: true`), and domain workflow failure states (`isError: false`).
