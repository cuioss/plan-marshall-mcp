== Overview

This document specifies the technical design, process management, security controls, and output parsers for the PM-MCP **Job Runtime**. The runtime manages native host subprocesses for builds, the git and CI operations of the CLI variant (`git`, `gh`, `glab`), out-of-process project scripts (`PM-EXT-5`), and the workers, jobs of kind `llm` that run the headless CLI of an enrolled harness for a role (link:model-work/04-worker-launch.adoc[Model Work Specification, Worker Launch]), under strict operator enrolment (`PM-EXEC-1`..`PM-EXEC-5`). Every job is awaited by the engine as an event; the only calls a model holds open are a worker's `pm_wait` and a running `pm_build`, served by the bounded and progress wait primitives. The git and CI operations of the native variant run in-process; they get a job record without process fields and the same budgets, cancellation, and outcome rules (xref:job-runtime/01-pipeline-and-subprocesses.adoc#in-process-operations[In-Process Operations (Native Variant)]). The runtime never executes `plan-marshall` scripts (`PM-MIG-2`). The git and CI operation contracts that these jobs serve live in the provider modules `pm-provider-git` and `pm-provider-ci`, the findings and code-analysis contracts in `pm-core` (link:module-structure.adoc#findings-analysis-contracts[Module Structure § Findings & Code-Analysis Contracts]); their CLI adapter variants run as jobs of this runtime (link:../Requirements.adoc#PM-IMPL-1[PM-IMPL-1]).
