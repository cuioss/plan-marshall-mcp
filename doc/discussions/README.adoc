This directory holds research notes and proposals. Nothing here is part of the target design unless a requirement or specification adopts it.

Research notes reflect a point-in-time view of external projects and specifications. Recheck their sources before relying on them.

* xref:execution-patterns.adoc[Execution Patterns] — how comparable tools place coordination and execution, and how they handle builds that start containers.
* xref:mcp-skills-extension.adoc[MCP Skills Extension] — analysis of SEP-2640 and what it does and does not provide.
* xref:skills-host-support.adoc[Skills Host Support] — support status of the Skills extension in Claude Code, OpenCode and Antigravity.
* xref:container-build-measurements.adoc[Container Build Measurements] — cost of a fresh container per build.

== Proposals

A proposal for a change of the requirements or specifications is written here as `<topic>.adoc` and listed in this section. Once it is decided and applied to the requirements and specifications, the proposal document is deleted.
