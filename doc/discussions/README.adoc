This directory holds the analyses, research and variants behind the concept. The decisions themselves live in the concept documents one level up; nothing here is part of the target design unless a concept document adopts it.

Research documents reflect a point-in-time view of external projects and specifications. Recheck their sources before relying on them.

== Analyses and research

* xref:mcp-skills-extension.adoc[MCP Skills Extension] — analysis of SEP-2640 and what it does and does not provide.
* xref:skills-host-support.adoc[Skills Host Support] — support status of the Skills extension in Claude Code, OpenCode and Antigravity.
* xref:technology-evaluation.adoc[Technology Evaluation] — Quarkus MCP Server assessment, official SDK comparison, Python runtime options.
* xref:execution-patterns.adoc[Execution Patterns] — how comparable tools place coordination and execution, and how they handle builds that start containers.
* xref:container-build-measurements.adoc[Container Build Measurements] — cost of a fresh container per build.
* xref:local-endpoint-authentication.adoc[Local Endpoint Authentication] — _superseded 2026-09-28 by xref:client-architecture.adoc[Client Architecture]_ (Unix socket with runtime token file, web access through the separate `pm-mcp-web`); what a credential on the loopback endpoint protects; cookie file instead of signed tokens; TokenSheriff for later.
* xref:store-and-config-model.adoc[Store and Configuration Model] — clean-slate proposal for configuration files, store inventory, versioning without a migration chain before 1.0, import mapping, lesson and entry records; decisions Z3-1 to Z3-19 decided 2026-09-28; import withdrawn.
* xref:git-provider-modules.adoc[Git and Provider Modules] — native in-process git, GitHub and GitLab implementations with an agent identity as default and the CLIs as operator variant; module structure (`pm-mcp-providers` with `pm-mcp-git`, `pm-mcp-ci`, `pm-mcp-github`, `pm-mcp-gitlab`), library evaluation, credential model, resolution of the open git/GitHub/GitLab design topic; decisions Z2-1 to Z2-34 decided 2026-09-28 and applied to the specifications.
* xref:client-architecture.adoc[Client Architecture] — local adapter trusting same-user clients over a Unix socket with a runtime token file, separate native CLI binary (`pm-mcp-clients/pm-mcp-cli`), web adapter with one-time-code pairing and device bearer tokens, SvelteKit web app, web server as separate client process, OAuth seam; decisions Z1-1 to Z1-21 decided 2026-09-28.

== Variants for later verification

* xref:container-backend.adoc[Container Backend] — builds in short-lived containers through Docker or Podman, runtime adapter, builds that start containers.
