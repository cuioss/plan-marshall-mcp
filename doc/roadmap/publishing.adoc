== Purpose

plan-marshall-mcp is moving from an open-source project to a proprietary product. Until a product distribution
exists, *nothing is published to an external repository*: builds and artifacts stay local. This document records what
was switched off, where, and what still runs, so that no publishing path is re-enabled by accident.

== Licensing

* The code is proprietary, all rights reserved (link:../../LICENSE.md[LICENSE.md]); source headers carry
  `SPDX-License-Identifier: LicenseRef-Proprietary`.
* The last state published under FSL-1.1-ALv2 is the tag `fsl-final` (`47c9cfc`). Release 0.1.0 on Maven Central and
  every commit up to that tag stay FSL-1.1-ALv2; the grant cannot be revoked.
* External contributions are not accepted (link:../../CONTRIBUTING.md[CONTRIBUTING.md]); the repository's interaction
  limit is "collaborators only".
* The repository stays public for now so that the free SonarQube Cloud and CodeRabbit plans keep working; it moves to a
  private repository before the first beta.

== Publishing Switched Off

[cols="2,3,2",options="header"]
|===
|Path |Switched off by |File

|Release to Maven Central (version bump or manual dispatch)
|Release workflow removed
|`.github/workflows/release.yml` (deleted)

|Release runbook
|Skill removed
|`.claude/skills/release/` (deleted)

|Snapshot deploy to Maven Central
|`enable-snapshot-deploy: false`; the CI build no longer receives Sonatype or GPG credentials
|`.github/project.yml`, `.github/workflows/maven.yml`

|GitHub release and GitHub Pages at release
|`create-github-release: false`, `deploy-at-release: false`
|`.github/project.yml`

|`mvn deploy` from any machine
|`central-publishing-maven-plugin` (bound to `deploy` by the parent with `autoPublish=true`) set to `skipPublishing=true` and `autoPublish=false`; `maven.deploy.skip=true`
|`pom.xml`

|Maven repository and site targets
|`distributionManagement` points at `target/local-deploy` and `target/site-deploy` instead of Maven Central and `cuioss.github.io`
|`pom.xml`
|===

The Sonatype, GPG and release-app credentials are organisation secrets of `cuioss`; no workflow of this repository
passes the publishing credentials any more.

== What Still Runs

* *CI build* (`maven.yml`): compile, tests, quality gates and the SonarQube Cloud analysis; required check
  `build / conclusion`.
* *Integration tests* (`integration-tests.yml`); required check `integration-tests / conclusion`.
* *Dependency review*, *Dependabot auto-merge* and *OpenSSF Scorecard* — none of them publishes artifacts.
* *Local builds*: `compile`, `verify`, `-Ppre-commit`, `-Pcoverage`, `-Pintegration-tests` and `install` (into the local
  Maven repository) work unchanged; `deploy` writes only to `target/local-deploy`.

== Re-enabling

Publishing is re-enabled only by an explicit decision of the owner, and then not to Maven Central: the product
distribution is planned as signed native binaries in a dedicated public release repository with a Homebrew tap and an
install script, built by a native release pipeline that replaces the removed workflow.
