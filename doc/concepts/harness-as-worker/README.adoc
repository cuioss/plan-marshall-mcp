*Harness as worker* is the concept in which `PM-MCP` drives plans and epics, and harness processes with their models are workers that the server starts, offers tasks, watches, and replaces. The model contributes judgment and work; it never decides what happens next.

The interactive harness session with the user is the entry and a viewer: it turns the user's words into a plan or an epic and shows what runs. Everything inside a running plan or epic is either server logic or a task for a worker of a role.
