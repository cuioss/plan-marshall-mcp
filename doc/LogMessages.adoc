= Log Messages
:toc: left
:toclevels: 2
:nofooter:

All messages are defined in `de.cuioss.pm.mcp.PmMcpLogMessages` with prefix `PM_MCP`.
Identifier ranges: INFO 001-099, WARN 100-199, ERROR 200-299.

== INFO Level (001-099)

[cols="1,1,2,2", options="header"]
|===
|ID |Component |Message |Description
|PM_MCP-1 |HelloTool |Hello tool invoked for '%s' |Logged when the `hello` MCP tool is called
|===

== WARN Level (100-199)

[cols="1,1,2,2", options="header"]
|===
|ID |Component |Message |Description
|PM_MCP-100 |EffectiveConfigurationResolver |Effort configuration key '%s' is not in the role registry |Logged when the effort configuration (`workflow.json`) names a role group or sub-key the role registry does not know; the key is a validation error, reported as an `unknown_config_key` finding by the validation on read of the effective configuration (link:specification/dispatch-and-effort/03-escalation-roles-readers.adoc#_role_registry_lookup_hierarchy[Dispatch & Effort, Role Registry & Lookup Hierarchy]). Planned; not yet implemented
|===
